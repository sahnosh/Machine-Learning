# Machine-Learning
A collection of machine learning projects, experiments, and notebooks.

## Projects

| Project | Task | Tools |
| --- | --- | --- |
| [Iris Flower Classifier](projects/iris-classifier/) | Predict one of three Iris species from four flower measurements | Python, scikit-learn |
| [Handwritten Digit Image Classifier](projects/digit-image-classifier/) | Classify 8x8 grayscale images of handwritten digits 0-9 | Python, NumPy, scikit-learn |
| [Movie Recommendation System](movie-recommender/) | Recommend unseen movies with collaborative filtering and a popularity baseline | Python, NumPy |
| [Customer Segmentation](customer-segmentation/) | Explore RFM customer groups with K-means and a web interface | Python, NumPy, pandas, Streamlit |

Each project includes its own setup instructions, source code, and tests.
